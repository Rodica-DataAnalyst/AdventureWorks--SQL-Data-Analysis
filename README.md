# AdventureWorks SQL Data Analysis

## Project Overview

This project demonstrates SQL data analysis using the AdventureWorks database in Microsoft SQL Server. The project contains a series of practical SQL tasks designed to explore, filter, aggregate, and analyze business data.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- AdventureWorks Database

## SQL Skills Demonstrated
- SELECT statements
- WHERE filtering
- ORDER BY
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries
- Common Table Expressions (CTEs)
- CASE expressions
- Date functions
- String functions
- Window functions
- ROW_NUMBER, RANK and DENSE_RANK
- Data analysis using multiple related tables

## Analysis Performed
The project includes SQL queries for:
- Product and sales analysis
- Customer analysis
- Filtering and sorting business data
- Sales aggregations
- Comparing products and categories
- Identifying top-performing products
- Working with dates and sales periods
- Ranking and analytical calculations

## Project File
AdventureWorks_SQL_Data_Analysis.sql

The SQL file contains the queries and solutions developed as part of the project.

## Database

The project uses the Microsoft AdventureWorks sample database.
